Implement reusable, case-sensitive selectors parsed from `resource-type:resource-id-pattern:property-pattern`, with wildcard matching in all three components and deterministic, case-sensitive resolution.

Malformed selectors return `SelectorError` without a usable selector. Resolution is immutable, deduplicates overlaps in configuration order, preserves selector input order, and distinguishes unmatched resources from known resources with ineligible properties.

Selected results, diagnostics, completed retry results, and cancellation errors must pass unchanged through `ValidateScopedResults` from `github.com/goss-org/goss` and formatted validation. Scoped Addr, Command, DNS, File, HTTP, Interface, Matching, and Gossfile validation must perform only selected work while preserving applicable retries, identities, ordering, prerequisites, skipped results, warnings, matcher behavior, and probe closure.

Addr supports only `reachable`; Command supports `exit-status`, `stdout`, and `stderr`; DNS supports `resolvable` and `addrs`; HTTP supports `status`, `headers`, and `body`; Interface supports `exists`, `addrs`, and `mtu`; Matching supports only `matches`; Gossfile exposes no selectable validation properties, so every property request is ineligible and ordinary validation remains resultless.
