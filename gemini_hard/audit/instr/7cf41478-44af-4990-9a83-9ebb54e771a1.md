Let Risor embedders create transactional, independently usable copies of runtime object graphs and opt into isolated globals for evaluation. Copies preserve graph topology and runtime behavior while preventing mutable state from leaking between executions. Isolation remains opt-in, leaving existing Eval and Run behavior unchanged by default.

`CloneObject` and the `Cloneable` contract in `github.com/deepnoodle-ai/risor/v2/pkg/object` preserve aliases and cycles, separate copied mutable identities from originals, and account for each distinct source object once under `CloneLimits`. Cells, Closures, Regexp values, Colors, Ranges, Modules, and Partials retain their established observable behavior while recursively copying mutable captures, contents, and arguments in one `CloneContext` transaction. External DynamicAttr, GoFunc, and GoStruct values obey `ClonePolicy.ExternalValues` without invoking resolvers, and `ExternalValueReject` and `ExternalValueRetain` respectively reject or consistently retain host identities. Every failure, including depth or object limits, returns a path-bearing `CloneError` using `ClonePathSegment` and publishes neither a `CloneResult.Value` nor reusable partial state. The object package also exports `CloneResult`, `ExternalValueMode`, and `CloneOption` with the contracted roles in copying and resource accounting. `WithIsolatedGlobals` from `github.com/deepnoodle-ai/risor/v2/pkg/vm` installs a complete copied global graph before execution begins, or executes no instruction when copying fails. `IsolationOptions` and `WithObjectIsolation` from `github.com/deepnoodle-ai/risor/v2` expose the same isolation policy through Eval and Run while preserving native results, errors, and environment sharing when isolation is absent.
