Add field-access policies to DB chains. Preserve existing behaviour.

For Create, policies receive a resolved FieldAccessRequest with nonnil Context, Schema, Field and Statement, FieldOperationCreate and FieldAccessWrite. Distinguish condition, projection, destination and relationship-key purposes.

Omit denied create fields from SQL while retaining allowed fields and uniform batch rows. Database defaults and generated primary keys still populate permitted values. Struct, map and single-column updates must not change denied fields; mixed struct/map updates still write permitted fields.

Denied struct or map conditions using model or database names return *FieldAccessDeniedError identifying the field, FieldOperationQuery and FieldAccessCondition, with no query results. Automatic projections omit denied fields; explicit selection returns a denial with FieldAccessProjection.

Find into pointers and slices consumes rows while withholding denied destination fields and preserving permitted neighboring values and row order. Traditional and generic G.Find return equal redacted results without errors. Many-to-many preload matches each child to its parent, retaining cardinality and permitted values while redacting denied scalar fields.

Association Append preserves links and permitted related values while omitting denied scalars. Association Replace denied on a required relationship key returns a typed field denial and preserves the previous relationship.

An allow-all policy produces the same dry-run Create SQL, variables and error as no policy.

These are required in what you deliver from gorm.io/gorm:

- FieldOperation with FieldOperationCreate and FieldOperationQuery; FieldAccessPurpose with FieldAccessWrite, FieldAccessCondition, FieldAccessProjection, FieldAccessDestination, FieldAccessRelationshipKey.
- FieldAccessRequest{Context context.Context; Operation FieldOperation; Purpose FieldAccessPurpose; Schema *schema.Schema; Field *schema.Field; Statement *Statement}.
- FieldAccessPolicy with AllowField(FieldAccessRequest) (bool, error); FieldAccessPolicyFunc func(FieldAccessRequest) (bool, error), implementing AllowField.
- FieldAccessDeniedError{Operation FieldOperation; Purpose FieldAccessPurpose; Field string}, usable as an error.
- (*DB).WithFieldAccessPolicy(FieldAccessPolicy) *DB.
