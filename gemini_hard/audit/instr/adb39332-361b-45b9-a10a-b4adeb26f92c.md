Give every pterm text printer a reusable per-call rendering context so concurrent destinations can choose independent writers, widths, styling, and color capabilities without mutating package globals. Contextual printing must also expose the writer's actual outcome while preserving each printer's established rendering and terminal side effects.

A zero-value `TextContext` makes every `ContextTextPrinter` behave byte-for-byte like its existing operations under current globals, including ordinary `SectionPrinter` styling and padding. Explicit context choices are immutable call-local overrides, isolated from concurrent contexts, global changes, and subsequent ordinary calls. Across `BasicTextPrinter`, `BoxPrinter`, `CenterPrinter`, `HeaderPrinter`, `ParagraphPrinter`, `PrefixPrinter`, `SectionPrinter`, `Color`, `RGB`, and `RGBStyle`, every contextual operation is its corresponding established operation evaluated entirely under the resolved context, preserving all printer-specific argument interpretation, formatting, layout, suppression, reset, Unicode, and terminal side-effect semantics. This equivalence includes `SprintContext` and `SprintfContext` argument handling, line-wise styling, box and header geometry, and every prefix mode and annotation. Positive width controls all wrapping, centering, and full-width geometry without splitting overlong words or producing negative padding; `WithTextStyling(TextModeRaw)` alone bypasses paragraph wrapping. Styling formats basic text in the established order and line-wise form, while color projection preserves visible text, repairs nested resets, and emits only sequences supported by the selected profile. `PrintContext` performs at most one write to the resolved writer, returns its byte count and error unchanged, and performs no write when output or debug behavior suppresses the operation. Fatal prefix output reports the contextual write outcome before completing its existing fatal action. `WithTextWriter(writer)`, `WithTextWidth(width)`, `WithTextOutput(mode)`, `WithTextStyling(mode)`, and `WithTextColorProfile(profile)` construct the corresponding `TextContextOption`; all public names are exported from `github.com/pterm/pterm`.

Concurrent narrow plain and wide styled contexts render centered text and headers without exchanging widths, styles, colors, or writers. One explicit color profile flows through BasicTextPrinter, Color, RGB, and RGBStyle while each retains its distinct reset handling. A shared explicit width drives box geometry, centering, header wrapping, and paragraph wrapping according to each printer's rules. A fatal PrefixPrinter using a short failing contextual writer reports that outcome before fatal completion. Nested styling and Unicode layout retain established reset boundaries, visible row widths, and spacing under contextual ANSI projection.
