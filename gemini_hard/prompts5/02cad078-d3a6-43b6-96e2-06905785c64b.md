The repository at `/workdir` is `chardet`, a universal character encoding detector for Python.
`detect()` and `detect_all()` run bytes through a staged detection pipeline and report an
encoding, a confidence, a language and a MIME type; `UniversalDetector` does the same for
streamed input; the `chardetect` command-line tool wraps it; and the maintainer scripts train its
models, evaluate its accuracy and generate its documentation tables.

Fix all implementation drift from the documentation in this repository.
