directory of revision scripts linked into a graph, resolves revision identifiers and ranges, runs
upgrades, downgrades and stamps online or as offline SQL scripts, provides the `op` migration
operations (including SQLite "batch" mode), autogenerates candidate migrations by comparing a
database with SQLAlchemy metadata, and exposes all of this through the `alembic` command line
and the `alembic.command` / `alembic.config` API.
