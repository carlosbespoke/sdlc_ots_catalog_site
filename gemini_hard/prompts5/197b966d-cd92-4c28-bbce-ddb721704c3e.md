The repository at `/workdir` is `graphviz`, a pure-Python interface to the Graphviz graph drawing
software: `Graph` and `Digraph` objects that assemble DOT source code (nodes, edges, attribute
statements, subgraphs, quoting and escaping of identifiers and labels), a `Source` class for
verbatim DOT strings and files, and wrappers that save the source, render and pipe it through the
Graphviz layout command, run the `unflatten` preprocessor, report the installed Graphviz version
and display graphs in Jupyter. The Graphviz command-line tools are installed in this environment.
