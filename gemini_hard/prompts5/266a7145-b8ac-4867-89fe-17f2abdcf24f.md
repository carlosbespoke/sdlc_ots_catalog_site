collection of implementations for a uniform, pythonic interface to local, in-memory, archive,
cached and remote file systems.

Fix all implementation drift from the documentation in this repository.
Everything in scope is the fsspec package under fsspec/ together with the documentation that describes it: the README and the Sphinx pages under docs/source (index, intro, usage, features, copying, async, api and developer), which render the package docstrings.

change the implementation so that it does what the documentation says, and do not edit or delete
documentation to make a disagreement go away. The documentation includes the docstrings and
doctest examples in the package. Behavioral comments inside the code are supporting evidence
only; when they conflict with the documentation, follow the documentation.

Keep the public API stable and keep every behavior that already matches its documentation
working exactly as it does now.
