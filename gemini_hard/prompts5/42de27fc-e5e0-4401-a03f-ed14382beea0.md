The repository at `/workdir` is `blessed`, a Python library for building terminal applications:
a `Terminal` class that exposes terminfo capabilities as attributes and callable formatting
strings (styles, 16/256/24-bit colours, hyperlinks), measures, pads, wraps and splits text that
contains terminal sequences, decodes keyboard and mouse input into keystrokes and events
(including the kitty keyboard protocol), queries and sets DEC private modes, cursor position and
shape, and offers a line editor and colour-space utilities, with example programs under `bin/`.
