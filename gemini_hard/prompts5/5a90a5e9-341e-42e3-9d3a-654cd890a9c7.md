The repository at `/workdir` is Apprise, a Python notification library: it turns `service://` URLs
into notification plugins, filters them by tags with priorities and retries, converts message
formats, loads URLs from configuration files and sends attachments, and delivers each notification
through the matching plugin.

Fix all implementation drift from the documentation in this repository.

change the implementation so that it does what the documentation says, and do not edit or delete
documentation to make a disagreement go away. The documentation is the in-package docstrings,
including their examples; in-package code comments, including the URL notes at the top of each
plugin module, are only supporting evidence, and when a comment conflicts with a docstring, follow
the docstring.
