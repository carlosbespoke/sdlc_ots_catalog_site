Add scoped utility resource limits. Preserve existing behaviour.

Budget.consume charges named dimensions atomically; rejection leaves usage unchanged and raises UtilityLimitError with dimension, limit, attempted charge and prior usage. Snapshots have immutable, detached amounts. Child charges debit child/parent once and cannot exceed parent limits. Budget scopes select/restore ambient accounting; explicit parser budgets charge independently and restore ambient work.

LRUCache supports type subscripting and accounts retained items/weights; replacement releases old weight. Rejected new inserts preserve contents and usage. search_dict charges only reached traversal, enforces visited-container/depth limits independently and restores the enclosing scope when a partial generator closes.

load_module/exec_module enforce import attempts; load_module also enforces source bytes before publication. Failed first execution leaves no partial module; failed overriding execution restores the old module and propagates the original error.

JSON/HTML/XML/query parsers reject excess input bytes without charging rejected input. JSON/HTML/XML enforce output_nodes; JSON counts mapping/list containers, excluding scalars. Query parsing enforces decoded_pairs without returning partial mappings. Bounded XML retains namespace/entity options. absolute_url enforces input/output characters; update_qsd rejects encoding expansion without charging rejected output.

Deferred parser validators select execution-time budgets, share sequential accounting and propagate UtilityLimitError. Plugin parsing/search/validation share a streams-operation budget, exposed afterward by utility_usage(). Session limits remain independent, including explicitly constructed options; repeated successful streams calls start fresh. Cached module identities survive repeated operations.
