The repository at `/workdir` is Captum, a model-interpretability library for PyTorch. Its attribution
subsystem assigns importance scores to the inputs, hidden layers and neurons of a PyTorch model:
gradient-based methods (saliency, input x gradient, integrated gradients, DeepLift, gradient SHAP,
guided backpropagation, deconvolution, GradCAM, LRP), perturbation-based methods (feature ablation,
feature permutation, occlusion, Shapley value sampling, LIME, KernelSHAP), noise tunnel, layer and
neuron variants of these methods, baselines, batching, summarizers and visualization helpers.

Fix all implementation drift from the documentation in this subsystem.
Everything in scope is Captum's attribution subsystem: the captum.attr package under captum/attr/ and the shared helpers it uses under captum/_utils/ (__init__.py, common.py, gradient.py, progress.py, typing.py, exceptions.py and the models/ package), together with the documentation that describes them: their docstrings, README.md, docs/attribution_algorithms.md, docs/algorithms_comparison_matrix.md, docs/faq.md and docs/extension/integrated_gradients.md.
